## Image Optimization Tips

### before uploading:

1. **Resize Images**
   - Use tools like ImageResizer.com or Photoshop
   - Crop to recommended sizes above
   - Maintain aspect ratios

2. **Compress for Web**
   - Use TinyPNG.com or ImageOptim
   - Target: 100-400KB per image
   - Balance quality with file size

3. **Format**
   - Use JPG for photographs
   - Use PNG for graphics with transparency
   - Avoid BMP or TIFF formats

4. **Naming Convention**
   - Use the exact filenames mentioned above
   - Use lowercase letters only
   - No spaces in filenames (use slide1.jpg, not "slide 1.jpg")

### Tools Recommended:
- **Compression**: TinyPNG, ImageOptim, Compressor.io
- **Resizing**: Photoshop, GIMP, Canva, Pixlr
- **Bulk Processing**: ImageMagick, Adobe Lightroom
- **Online**: Canva, Pixlr Editor, Photopea

## Content Strategy

### Photography Tips:
1. **Authenticity**: Use real moments, not staged photos
2. **Diversity**: Show different activities and children
3. **Action Shots**: Capture movement and engagement
4. **Emotions**: Include genuine smiles and interactions
5. **Lighting**: Photograph during daytime for best natural light
6. **Backgrounds**: Keep clean, uncluttered backgrounds

### Storytelling:
- Use photos to tell the story of your organization
- Show progress and impact
- Highlight different programs and activities
- Include staff and volunteers
- Show the emotional connection

### Best Practices:
- Never publish photos without proper consent
- Protect children's privacy and dignity
- Use images that represent your mission
- Keep image usage consistent with organization values
- Update images regularly to keep content fresh

## Testing

After adding images:

1. **Check File Names**: Ensure exact matching (case-sensitive on some servers)
2. **Test in Browser**: View each page to verify images load
3. **Check Responsiveness**: Test on mobile, tablet, and desktop
4. **Optimize Load Time**: Test site speed with WebPageTest.org
5. **Cross-Browser**: Test in Chrome, Firefox, Safari, Edge

## Alternative: Using External Image Services

If you don't want to host images locally, consider:

1. **Imgur**: Free image hosting
2. **Cloudinary**: Free CDN image service
3. **Amazon S3**: Scalable image storage
4. **Google Cloud Storage**: Cloud image hosting

Just update the `src` attributes in HTML files to point to external URLs.
